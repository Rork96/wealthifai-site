Case 01 · Google Apps ScriptIn production

Weekly task emails for restaurant managers

Tim Hortons restaurants, Winnipeg

Problem

Built

Case 03 · Multi-agent backendOpen source

Jobif: streaming AI interview with billing

SaaS backend with payments

Problem
Rewriting a resume for each posting is slow, and generic chat tools do not score against the job description.
Built
Upload a PDF, DOCX or TXT and paste a job link. The service returns an ATS match score with found and missing keywords, then runs a streamed interview that rewrites bullets live, followed by a final polish pass.
Hardening
Model fallback chain, JSON recovery for broken model output, Stripe webhooks with HMAC verification, JWT checks and row-level security in Supabase.
